## 0. Weekly targets from Arman's Excel  ← BIGGEST, do first (unblocks Daily/Office/Funnel)

**Ask:** "Targets as per Capricorn targets Excel — Arman updates first thing Monday, we track
Actuals against weekly Targets." Applies to: Daily Run Chase, Office Run Chase, and Funnel's Daily
Revenue Target. Today these are strawman placeholders in `src/domain/targets.ts` (wrong scale — why
apps/refs/sales read "critical").

**Decision needed (pick one) — where the targets Excel lives + how the app reads it:**
1. **SharePoint/OneDrive file read via Microsoft Graph (recommended).** Arman keeps one workbook in
   a known SharePoint location; the app reads it with its managed identity (grant the MI
   `Sites.Selected` on that site) on a short cache (re-read hourly + a forced refresh Mon 09:00
   Europe/London). No new infra, Arman edits a normal Excel. Needs: the SharePoint site/file path +
   MI grant.
2. **Blob upload.** Arman drops the file in a storage container; app reads it. Simpler auth (MI
   Storage Blob Data Reader) but Arman needs a blob upload step (Storage Explorer / a small upload
   page).
3. **Targets table in the lake.** Land targets as a `GAGold_Capricorn` table via the reporting ETL;
   app reads it like any dataset. Cleanest read path, but requires a `Smartr365.Reporting.Workspaces`
   change + Arman editing a source the ETL picks up (not a plain Excel) — slower, more moving parts.

**Recommendation:** Option 1. Confirm the SharePoint location with Arman/Kyle.

sales} **weekly** targets, plus a **weekly revenue target** (business + optionally per office).

row).
